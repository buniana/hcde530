# HCDE 530 Week 2 Project

This project demonstrates how to process a CSV data file effectively and present results in two formats:

- terminal output from a Python script
- a browser-based dashboard

## Project goals
- Keep setup minimal and easy for anyone to run.
- Show participant role demographics from the current dataset.
- Show grouped main themes using automatic keyword grouping.
- Keep code beginner-friendly, with comments on key logic.

## Files
- `demo_responses.csv`: source interview response data.
- `demo_word_count.py`: Python script for response length analysis.
- `demo_dashboard.html`: lightweight, polished web dashboard.
- `PROJECT_CONTEXT.md`: detailed project context and coding preferences.

## How to run
1. Open Terminal.
2. Go to this folder:
   `cd "/Users/linawang/Documents/HCDE 530/hcde530/HCDE 530 Week 2 Project"`
3. Run the script:
   `python3 demo_word_count.py`
4. Open the dashboard:
   `open demo_dashboard.html`

## Notes
- The current scope uses participant role as the demographic field.
- Theme grouping should be reasonably accurate using a curated keyword list.
